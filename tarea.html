Tarea: ¡Llena la Cuarta página!

La Cuarta pagina está casi vacía. Vamos a llenarla usando todo lo que ya sabes.
Haz las misiones en orden. Si te atascas, pulsa Ver pista.

Misión 1: Un link nuevo en el menú

Esta página (tarea.html) no sale en el menú de tus otras páginas.

  • Añade un link que diga Tarea en el menú de las 4 páginas.
  • Debe ser blanco, igual que los otros links.

Busca el <div> negro de arriba en cada página. Copia una línea de link y cambia el href y el texto:

<a style="color:white;" href="tarea.html">Tarea</a>

Misión 2: Foto y párrafo

En cuarta-pagina.html, debajo del título:

  • Pon la foto foto2.jpg.
  • Debajo de la foto, escribe un párrafo que cuente 3 cosas que te gustan.

Mira cómo pusiste la foto en tercera-pagina.html. Para un párrafo se usa la etiqueta <p>:

<p>Me gusta ...</p>

Misión 3: El título cambia de color

En la Cuarta pagina, añade un botón que diga Cambiar color.

  • Si el título está verde, al hacer clic se pone azul.
  • Si está azul, vuelve a verde.

¡Es casi igual que tu función ocultarYmostrarTitulo() de index.html!

1. Ponle un id al <h1> para poder encontrarlo.
2. En vez de style.display usa style.color:

if(titulo.style.color == "green"){
  titulo.style.color = "blue";
}else{
  ...
}

Misión 4: La contraseña secreta

En la Cuarta pagina, añade una caja de texto y un botón que diga Entrar.

  • Si alguien escribe tato123, sale el mensaje: "¡Bienvenido, agente secreto!"
  • Si escribe otra cosa, sale: "Contraseña incorrecta"

Mira tu función saludar() de segunda-pagina.html. Es lo mismo, pero con otras palabras dentro del if y del alert.

Ojo: ponle a la caja un id nuevo, por ejemplo id="clave", y usa ese mismo nombre en getElementById.

⭐ Misión extra: Modo oscuro

Añade un botón Modo oscuro que cambie el fondo de toda la página a negro y las letras a blanco. Si lo pulsas otra vez, vuelve a blanco.

La página entera es el body. Puedes cambiarla así, sin getElementById:

document.body.style.backgroundColor = "black";
document.body.style.color = "white";

Usa un if / else para saber si ya está negra.

🚀 Misión final: ¡Publica tu trabajo!

Cuando todo funcione, guárdalo con un commit y súbelo a internet con un push.

  1. Abre la pestaña de Source Control en VS Code (el icono de las ramitas a la izquierda).
  2. Verás los archivos que cambiaste. Revisa que estén todos.
  3. Escribe un mensaje que diga lo que hiciste, por ejemplo: "Tarea: cuarta pagina terminada".
  4. Pulsa Commit.
  5. Pulsa Sync Changes (o Push) para subirlo.
  6. Espera un minuto y abre tato.javierfolder.com/cuarta-pagina.html en el teléfono. ¡Tu trabajo ya está en internet!

También lo puedes hacer escribiendo en la terminal:

git add .
git commit -m "Tarea: cuarta pagina terminada"
git push

add = elegir los archivos, commit = guardar una foto de tu trabajo, push = subirlo a internet.
